# Page Flipper

A web app for iPad that turns your printed sheet music into full-screen pages you can flip hands-free.

**Step 1 (this version):** photograph each page, straighten and clean it up, save pages as a piece, and play it full screen. Turn pages by tapping (left third = back, anywhere else = forward), swiping, or with a Bluetooth page-turner pedal (arrow / Page Up / Page Down keys).

Coming next: teach mode (play each page's last bar once) and auto-flip from the microphone.

Everything is stored on the device in the browser (IndexedDB). Nothing is uploaded.

## Use on iPad
Open the site in Chrome, then Share › Add to Home Screen so it opens full screen like an app.
